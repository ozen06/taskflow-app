# 📱 React Native + Expo App

Este es un proyecto creado a partir de **React Native + Expo**. El desarrollo de la aplicación abarca tanto el ecosistema **iOS** como **Android** indistintamente.

## Ejecución Local

Para hacer funcionar la aplicación en Expo, debes ejecutar:

```bash
npx expo start
```
